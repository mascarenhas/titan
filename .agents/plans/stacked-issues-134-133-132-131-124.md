## Issue scopes

### #134: logical truthiness

projections. Give `and`, `or`, and `not` the documented truthiness semantics
without weakening assignments, arguments, or returns. Preserve short-circuit
evaluation, operand order, existing Option behavior, and typed fast paths.
Add focused checker and execution regressions covering false/nil and truthy
values, nested operators, operand evaluation, and strict projection rejection.
Update the owning language and implementation documentation.

### #133: maybe-const compiled metadata

validator while rejecting malformed qualifiers. Cover exported fields and

### #132: checkout-aware focused Busted runs

Provide a supported way for focused tests to load the current checkout's Lua
compiler while keeping its installed SDK/runtime provider. Exercise a
deliberately stale installed module to prove source selection. Preserve the
canonical install-before-full-test route, forwarded Busted arguments and
filters, and private compiler-worker artifact ownership. Update commands and
agent guidance to describe the actual entrypoint.

### #131: optional Array constructor context

including generic inference. Keep the element/container assignment plan owned
by the checker and retain incompatible-element diagnostics. Add checker and
execution coverage for generic and nongeneric optional Array parameters and
the relevant constructor edges.

### #124: explicitly identified inherited stdio pipes

Inspect the existing parent-stdio ownership model before selecting a narrowly
scoped trusted-launcher mechanism. An explicit hint may identify supported
pipe endpoints when metadata inspection makes libuv return unknown; the
ordinary path must still reject regular files, TCP sockets, datagrams, and
other unsupported descriptors. Preserve duplication, close-on-exec, caching,
and Runtime cleanup. Add a deterministic denied-introspection regression and
an actionable classification diagnostic. Document the launcher contract in
both manuals and applicable skills. Ask about the intended invariant if a
design gap would otherwise require an architectural workaround.
