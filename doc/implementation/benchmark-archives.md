# Archived issue benchmarks

Benchmark harnesses, native probes, raw measurement tables, and historical
evidence bundles are not kept under `spec/bench/` in the repository tree.
Each is a GitHub pre-release ZIP asset, linked from its tracking issue. Every
archive preserves its original repository-relative paths and includes a
top-level `README.issue<N>.md` and a `SHA256SUMS` manifest.

## Verification and extraction

After downloading an archive from its pre-release page, verify its outer digest
against the index above and check its internal file inventory with:

```sh
unzip <archive-name>.zip -d <target-dir>
cd <target-dir>
sha256sum -c SHA256SUMS
```
